# 数据与业务契约

enrolled 为实际报名，不是未受容量约束的需求；waitlist 缺失表示未观测，不能当零。共享课程仍是一条 course，campuses 列出参与校区。known_at 是计划可被使用的最早时点，effective/target 是业务生效期。

## 数据集合

- `courses`：主键为 `course`；必填字段 `course, title, topic, campuses, capacity, introduced`，当前 9 条。
- `history`：主键为 `course + term`；必填字段 `course, term, published_at, seats, enrolled`，当前 64 条。
- `plans`：主键为 `plan`；必填字段 `plan, known_at, target, courses`，当前 2 条。
- `relations`：主键为 `relation`；必填字段 `relation, effective, known_at, parents, child, meaning`，当前 1 条。
- `reservations`：主键为 `campus + term`；必填字段 `campus, term, teacher_hours`，当前 3 条。
- `forecasts`：主键为 `release + course`；必填字段 `release, course, target, issued_at, point, plan`，当前 8 条。

集合中的主键不得重复；schema 的 foreign 引用须指向已存在的记录。可空字段保留 null 的业务含义，不自动补零。

## 查询与材料

GET 查询使用 UTF-8 JSON，错误参数返回 400，不存在的接口返回 404。重复的单值参数视为无效。summary 与 HTTP 调用同一组只读计算，材料包含数据内容指纹和生成时间，便于核对输入。当前输出描述已有数据，不承诺未实现的推断结论。

## 现有办理协作

当前 staffing.propose 记录课程组合与所需时段，teacher_contracts.confirm 由教师确认整段时间，admissions.publish 按已确认容量发布席位；未使用概率需求或课程计划回测证据。

每个操作在本地业务日志的事务中更新；失败不提交半条办理记录。已有人工流程可以继续使用，新增分析尚未作为这些操作的有效依据。接口传入业务标识，未知标识或不满足条件返回错误，不自动补建对象。
